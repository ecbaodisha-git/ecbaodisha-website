# ECBA ODISHA Website

Professional responsive static website for the All Odisha Environment Control Broilers Welfare Association.

## Deploy to GitHub Pages
1. Upload the **contents** of this folder to the root of your public GitHub repository.
2. Settings → Pages → Deploy from branch → main → /(root).
3. Wait for deployment, then optionally configure `ecbaodisha.org` as a custom domain and update GoDaddy DNS per GitHub Pages documentation.

## Pages
- `index.html`: home, about, issues
- `memorandum.html`: 15 key demands
- `member.html`: membership enquiry
- `health.html`: English/Odia general poultry guidance
- `contact.html`: contact enquiry
- `ecba-logo.jpg`: official user-provided logo

## IMPORTANT before launch
- Set `OFFICIAL_EMAIL` in `script.js` to the verified association email address. Without it, membership and contact forms do not send messages. They do **not** save registrations or issue member IDs.
- Health guidance is educational and does not diagnose disease or prescribe drugs/vaccines.
- The memorandum reflects proposed demands, not verified statutory rights.
- Verify association name, policies and contact details before publication.
- Google Fonts require internet; fallback fonts are provided.
